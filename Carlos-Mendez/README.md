# Mi Wallet Stellar

Entregable 1 del Bootcamp Pura Vida, hecho por Carlos Mendez.

## ¿Qué hace?

Es una página web simple donde el usuario puede conectar su wallet de Stellar. Al conectarla, muestra su dirección pública y su balance de XLM en testnet (la red de práctica de Stellar).

## ¿Cómo usé Stellar Raven?

Conecté Stellar Raven, el MCP oficial de Stellar, como asistente. Le pregunté qué wallet y qué librería usar para conectar una wallet desde una página web sin frameworks, y me guió hacia Varial (antes Freighter), la wallet oficial de navegador de Stellar.
